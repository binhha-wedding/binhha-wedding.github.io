Xuất Bản & Đồng Bộ Lên Mạng

Cách thức áp dụng thông tin mới cho toàn bộ khách mời trên mọi thiết bị.

Đã Cấu Hình Sẵn GitHub Token Deploy 1-Click

Token truy cập GitHub của bạn đã được tích hợp sẵn sàng vào hệ thống. Mỗi khi chỉnh sửa xong thiệp, bạn chỉ cần bấm nút "🚀 Xuất bản lên GitHub" ở góc dưới, dữ liệu sẽ tự động lưu và cập nhật lên mạng mà không cần nhập lại mã!

Trạng thái: Token hợp lệ & Có toàn quyền cập nhật repository binhha-wedding.github.io.

💡 3 Cách Lưu Dữ Liệu

1. Lưu & Xem thử ngay (Local):

Lưu tức thì vào trình duyệt máy này. Bạn có thể mở ngay trang thiệp để xem kết quả trước.

2. Xuất bản trực tiếp lên GitHub Pages (1-Click):

Nhập mã GitHub Personal Access Token (PAT) để hệ thống tự động đẩy file cấu hình data/main-data.json lên repository binhha-wedding/binhha-wedding.github.io. Sau 1 phút, tất cả khách mời vào xem đều thấy thông tin mới nhất!

3. Tải file JSON về máy:

Tải file main-data.json về máy để lưu trữ hoặc commit lên Git thủ công bất cứ lúc nào.

Chỉnh sửa xong, bấm nút bên phải để lưu hoặc xuất bản.
