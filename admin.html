🎵 Bài Hát Hiện Tại

Xuất Bản & Đồng Bộ Lên GitHub Pages

Cách thức để toàn bộ khách mời trên mọi thiết bị đều nhìn thấy thay đổi mới nhất.

💡 Các Tùy Chọn Lưu Dữ Liệu

1. Lưu & Xem thử ngay (Local):

Lưu trực tiếp vào trình duyệt máy này. Bạn có thể mở ngay trang thiệp để xem kết quả trước khi phát hành chính thức.

2. Xuất bản trực tiếp lên GitHub Pages (Đồng bộ vĩnh viễn):

Admin sẽ gọi GitHub API cập nhật file cấu hình data/wedding-data.json trên repository habinh-wedding/habinh-wedding.github.io. Khoảng 1 phút sau, toàn bộ khách mời vào từ mọi nơi đều thấy thông tin mới nhất!

3. Tải file wedding-data.json về máy:

Tải file cấu hình JSON về máy để lưu trữ hoặc commit lên Git thủ công bất cứ lúc nào.

Sau khi chỉnh sửa xong, bấm nút bên phải để lưu hoặc xuất bản.
