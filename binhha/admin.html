💡 3 Cách Lưu Dữ Liệu

1. Lưu & Xem thử ngay (Local):

Lưu tức thì vào trình duyệt máy này. Bạn có thể mở ngay trang thiệp để xem kết quả trước.

2. Xuất bản trực tiếp lên GitHub Pages (1-Click):

Nhập mã GitHub Personal Access Token (PAT) để hệ thống tự động đẩy file cấu hình data/binhha-data.json lên repository binhha-wedding/binhha-wedding.github.io. Sau 1 phút, tất cả khách mời vào xem đều thấy thông tin mới nhất!

3. Tải file JSON về máy:

Tải file binhha-data.json về máy để lưu trữ hoặc commit lên Git thủ công bất cứ lúc nào.

Chỉnh sửa xong, bấm nút bên phải để lưu hoặc xuất bản.
